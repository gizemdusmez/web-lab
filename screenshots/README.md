# Screenshots Klasörü

Bu klasör LAB-3 ekran görüntülerini içerir.

Beklenen dosyalar:
- `screenshot-mobile.png`  — 375 px genişlikte alınmalı
- `screenshot-tablet.png`  — 768 px genişlikte alınmalı
- `screenshot-desktop.png` — 1280 px genişlikte alınmalı

Tarayıcı DevTools → Responsive Mode ile her breakpoint'te
tam sayfa ekran görüntüsü alındıktan sonra bu klasöre kaydedin.
